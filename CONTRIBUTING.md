# Contributing to CRAI

Thank you for your interest in CRAI.

This repository is primarily a public product showcase and frontend project.

## Development

```bash
cd frontend
npm install
npm run dev
```

Build verification:

```bash
npm run build
```

## Contribution Principles

- Keep changes focused.
- Preserve the existing SaaS-style UI direction.
- Prefer accessible and understandable interfaces.
- Avoid unnecessary dependencies.
- Keep documentation synchronized with meaningful changes.
- Do not commit credentials, private datasets, model weights or proprietary implementation details.

## Pull Requests

A useful pull request should include:

1. What changed
2. Why it changed
3. How it was tested
4. Screenshots for significant UI changes

## Public Repository Boundary

Please do not add:

- Private backend implementation
- Private model weights
- Internal prompts
- Proprietary thresholds
- Private datasets
- Secrets
- Unpublished research artifacts

These belong in the private engineering environment.
