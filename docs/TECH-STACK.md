# CRAI Technology Stack

## Frontend

| Technology | Role |
|---|---|
| React | Component-based application UI |
| Vite | Development server and production build |
| JavaScript / ES Modules | Application implementation |
| React Hooks | Application state and lifecycle logic |
| Fetch API | Backend communication |
| Local Storage | Local application persistence |

## Backend

The engineering backend uses a Python/FastAPI architecture with REST APIs and structured configuration.

| Technology | Role |
|---|---|
| Python | Backend and AI ecosystem |
| FastAPI | REST API layer |
| Uvicorn | ASGI server |
| Pydantic | Validation and typed configuration |
| SQLAlchemy | Database access layer |
| SQLite | Local engineering persistence |

## AI / ML

CRAI combines computer-vision and analytical components with an LLM-assisted advisory layer.

Relevant technologies include:

- PyTorch
- TorchVision
- Computer Vision
- Image preprocessing
- Machine-learning risk modelling
- Model evaluation workflows
- Local LLM-assisted advisory
