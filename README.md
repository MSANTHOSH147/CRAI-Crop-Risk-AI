## 🌾 What is CRAI?

**CRAI (Crop Risk AI)** is an intelligent agriculture platform designed to help monitor crop conditions by combining multiple sources of agricultural evidence into a unified workflow.

Instead of depending on a single image or sensor reading, CRAI brings together:

| Intelligence Layer | Purpose |
|---|---|
| 🌿 **Crop Vision** | Analyze crop images for potential disease conditions |
| 🌡️ **Field Sensing** | Monitor environmental and field conditions |
| 🧠 **Risk Intelligence** | Combine available evidence into a broader crop-risk view |
| 💡 **AI Advisory** | Convert detected conditions into understandable agricultural insights |
| 📊 **Monitoring Platform** | Present observations and intelligence through a unified dashboard |
